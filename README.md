
# Smart File Renamer

## About

This is a simple Python practice project created to improve understanding of file handling and automation using Python.

The project automatically renames files inside a selected folder using a custom prefix and sequential numbering. It demonstrates how Python can be used to automate repetitive tasks that would otherwise require manual effort.

## Purpose

The main goal of this project is to practice:

- Working with files and folders
- Using Python's `os` module
- Handling file paths
- Automating everyday tasks
- Writing clean and readable Python code

## Features

- Rename multiple files at once
- Keep original file extensions
- Apply custom naming patterns
- Simple command-line interface

## Technologies Used

- Python 3
- os module
